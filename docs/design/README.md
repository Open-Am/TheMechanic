# Design notes

Game design and interface design live here, one file per topic. These are not decisions. When a design note settles something other work depends on, it becomes an ADR.

Planned before Phase 2:

- `interface.md`: layout, colour tokens, typography (system fonts only, no web requests), the inspect card as a bottom sheet, tray chips, timer.
- `animation.md`: the motion vocabulary (ADR 0008), sequencing, easing, camera behaviour, timing targets.
- `diagnostic-mode.md`: what the internal overlay shows and how it is enabled (ADR 0007).
