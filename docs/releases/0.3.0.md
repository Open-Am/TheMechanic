# 0.3.0

The first stage of realistic lighting, and the tool settings for Phase 3.

## Added

- Image-based lighting: a studio environment generated in code (Three.js `RoomEnvironment`), one key light, and PBR Neutral tone mapping, with every lighting number in `game/src/render/lighting.ts` (plan 0004, ADR 0014).
- A fallback to the simple two-light rig when a phone cannot build the environment map. In development, `?lighting=fallback` forces it (plan 0004, ADR 0014).
- A soft ground shadow under the machine, drawn in code from its footprint, as a stand-in for the Blender bake in Phase 3 (plan 0004, ADR 0014).
- The diagnostic overlay shows which lighting rig is active (plan 0004, ADR 0007).
- `npm run verify:phone -- --lighting fallback` checks the fallback rig.
- 166 tests, up from 156.

## Changed

- Placeholder colours follow the visual references: blue tank, black body, silver alternator end and fuel tap, black muffler, cream capacitor. Only `color` values in `machine.json` change.
- Node 24 is declared in `engines` and `.node-version`, and `@types/node` moved to 24 to match (plan 0004, ADR 0012).
- Git LFS tracks Blender files and texture sources under `assets/`; the repository's LFS hooks are installed. Blender backup files are ignored (plan 0004, ADR 0012).
- AGENTS.md documents the tool versions and the `BLENDER` variable (plan 0004, ADR 0012).

## Fixed

- Tray pictures were rendered offscreen without tone mapping or sRGB encoding, because Three.js applies those only on screen, so they came out darker and flatter than the scene. They now get both in code (plan 0004).

## Known gaps

- The real HDR environment, the Blender-baked ground shadow and the asset-pipeline budget checks wait for Phase 3.
- Lighting is tuned by eye on placeholder boxes in headless Edge. It will be retuned in Phase 3 against the real model and reference photos.
- The frame rate was measured only in headless Edge with software rendering: 113 fps with the environment, 119 with the fallback, at 4x CPU throttle. Not representative of a real low-end phone.
- JavaScript is 143.8 KB gzipped, up 3.5 KB for the environment code.
