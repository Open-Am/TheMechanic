# 0.1.0

Phase 1 of the brief: the rules of the game as pure code, with no graphics. Not a playable release.

## Added

- The complete rule set of the game as pure TypeScript in `game/src/core`: types, validator, reducer, replay, scoring, daily seed and constants (plan 0001, ADRs 0003, 0004, 0005).
- 63 tests under `game/tests`, including a boundary test that fails the build if any layer imports where ADR 0010 forbids (plan 0001, ADR 0010).
- `npm run play`, a text-mode player that solves every fault from an action log and prints each step and the score (plan 0001).
- The `gen950` machine and fault data with a `motion` per part (plan 0001, ADR 0008).
- Platform interfaces for storage, the daily, sharing, audio and the clock, with no implementations yet (plan 0001, ADR 0010).
- A part can be inspected where it sits when nothing covers it, driven by a `hiddenBy` field with a safe default (plan 0002, ADR 0011).

## Changed

- Nothing. First release.

## Fixed

- Nothing. First release.

## Known gaps

- No interface, no rendering. Phase 2.
- The refusal reason for putting a part back too early is named `dependents_missing`; the plan had written `dependents_installed`. The rule is as the brief states.
